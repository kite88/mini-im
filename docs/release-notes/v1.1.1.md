Go + Gin + GORM(PostgreSQL) + Redis 实现的即时通讯 / 客服系统。前端是 Vue2 + Axios 静态页，由后端直接托管，无构建流程、无外部图片资源。

本版是收尾版：修掉刷新页面时的**首屏闪烁**，仓库不再入库 `config.yaml`，README 截图与演示账号按真实运行实例重做。

## 修复

**首屏闪烁**：Vue 编译之前，DOM 里还是原始模板 —— `{{ }}` 会以纯文本显示，带 `v-show` 的浮层（表情盘、设置面板、弹窗遮罩）也还没被隐藏，所以刷新时能看到变量和表情闪一下。现在：

- 聊天页与登录页的根节点都挂上 `v-cloak`，编译完成（Vue 自动移除属性）之前整块隐藏；
- 编译期间用 `#boot-mask` 占位顶住画面（`mounted` 后移除），另有 6 秒兜底淡出：万一脚本加载或初始化失败，占位不会永久遮住页面；
- 带 `v-show` 的浮层与登录页的注册表单补了初始 `display: none`，即使 Vue 没接管也不会盖在页面上；
- 规则统一收在共用的 `common.css`，两个页面引用它的缓存串更新为 `?v=20261016`。

## 工程

- **README 截图全部重截**（PC 端 1280×800、登录 / 注册页 900×620、手机端 390×844）：截图取自真实运行的实例，演示账号与 `config.example.yaml` 的 `seed.accounts` 对齐（Mini-IM No. 1 / No. 2 / No. 3、Xiaoha、Xiaowu、Xiaozhu、GoForIt），界面标题统一为 `Mini-IM`；README / README.en.md 的演示账号表、`seed.accounts` 片段与接口示例里的昵称同步更新。

## 快速开始

```bash
docker compose up -d      # 启动 PostgreSQL + Redis
go run .                  # 默认 http://127.0.0.1:8280
```

目录里没有 `config.yaml` 时服务会先进初始化配置向导：浏览器打开 `http://localhost:8280/setup`，
填好数据库 / Redis 并保存后业务服务自动接管；也可以先 `cp config.example.yaml config.yaml` 改好再启动。

新库是空的，直接在登录页注册账号即可；也可以把配置里的 `seed.enabled` 改成 `true` 重启，
得到一组两两互加好友的演示账号（密码 `123123`），开箱即可互发消息。

## 产物

| 平台 | 归档 | 包内可执行文件 |
| --- | --- | --- |
| Windows | `mini-im-v1.1.1-windows-<arch>.zip` | `mini-im.exe` |
| Linux / macOS | `mini-im-v1.1.1-<os>-<arch>.tar.gz` | `mini-im`（权限 0755，解压即可运行） |

架构覆盖 amd64 / arm64，共 6 个平台。归档是顶层目录 `mini-im-v1.1.1-<os>-<arch>/`，内含可执行文件、
`version.txt`（版本号，启动脚本会打印它）、 `config.example.yaml`（配置模板，兼作初始化向导写回的底稿）、
`README.md` / `README.en.md`、`LICENSE`、`web/`（前端静态页必须与可执行文件放在一起）以及启动脚本
（Linux / macOS 为 `start.sh`，Windows 为 `start.bat`）。

归档里**不带 `config.yaml`**：首次启动会进入初始化配置向导（`http://localhost:8280/setup`），
填好数据库 / Redis 后写回，避免把开发用的默认 JWT 密钥发到用户机器上。

```bash
tar -xzf mini-im-v1.1.1-linux-amd64.tar.gz && cd mini-im-v1.1.1-linux-amd64
./start.sh                 # 等价于 ./mini-im，附加参数会原样透传
```

`checksums.txt` 是全部 6 个归档的 SHA256（LF 换行，Linux 下可直接 `sha256sum -c checksums.txt`）。
归档均为 `CGO_ENABLED=0` 静态编译，并内嵌 IANA 时区数据库。
